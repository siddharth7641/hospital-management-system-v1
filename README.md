Hospital Management System (HMS)
A Flask and SQLite web application designed to streamline hospital operations. This project provides a role-based system with dedicated portals for Admins, Doctors, and Patients to manage medical records and appointments efficiently.

Core Functionalities
Admin Portal: Manage doctor and patient profiles, oversee all appointments, and view key hospital statistics.

Doctor Portal: Access appointment schedules, update patient diagnosis and treatment notes, and manage weekly availability.

Patient Portal: Self-register and login, search for doctors by specialty, book/cancel appointments, and view personal medical history.

Technology Stack
Backend: Flask

Frontend: Jinja2, HTML, CSS, Bootstrap

Database: SQLite
